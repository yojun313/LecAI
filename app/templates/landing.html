강의 자료를 올리면
슬라이드마다 AI 설명이 붙습니다

PDF·PPT를 올리면 슬라이드 한 장 한 장을 AI가 읽고 한국어로 자세히 정리합니다. 강의 녹음본과 칠판 판서 사진을 추가하면 그 내용이 해당 슬라이드에만 정확히 연결되고, 슬라이드마다 AI에게 바로 질문할 수 있습니다.

무료로 시작하기 이미 계정이 있어요

분석에는 본인의 OpenAI API Key 를 사용합니다 · 강의 1편(60장) 분석 비용은 보통 수십 원 수준

무엇을 해 주나요

강의를 듣기 전, 듣는 중, 들은 뒤에 각각 필요한 것을 채워 줍니다.

슬라이드별 AI 설명

핵심 주제, 주요 내용, 도표·그림 설명, 핵심 정리를 슬라이드마다 작성합니다. 수식은 LaTeX로 정확히 표기하고 유형(정의·증명·예제·비교)에 맞게 설명합니다.

강의 녹음본 연결

녹음 파일(mp3 등)이나 텍스트·문서 파일을 올리면 음성 인식 후 강의자가 각 슬라이드에서 실제로 말한 내용을 찾아 그 슬라이드에만 발췌를 붙입니다. 인용은 원문과 대조해 검증합니다.

칠판 판서 사진

판서 사진을 여러 장 올리면 어느 슬라이드의 판서인지 판별하고, 수식을 한 줄씩 전사·설명한 절을 해당 슬라이드에 추가합니다.

슬라이드별 AI 질문

보고 있는 슬라이드의 이미지·설명·녹음·판서를 참고해 답하는 채팅. 대화 맥락이 슬라이드별로 유지되어 "더 쉽게", "예를 들어"처럼 이어서 물을 수 있습니다.

문서함과 뷰어

폴더로 정리하고 드래그로 옮기며, 발표 모드·스크롤 모드·전체화면으로 봅니다. 보관함, 자동 새로고침, PDF·Markdown 내보내기(범위·배율 지정)를 지원합니다.

토큰 비용 최적화

프롬프트 캐싱, 배치 API, 이미지 크기 조정으로 비용을 줄입니다. 녹음본은 캐시된 prefix로 전달되어 슬라이드마다 정가의 10% 로 읽힙니다.

사용 방법

  1. STEP 1
    가입 후 OpenAI API Key 등록

    설정 화면에 키를 붙여 넣으면 자동 저장됩니다.

  2. STEP 2
    PDF·PPT 업로드

    녹음본이 있으면 함께 넣고, 없으면 나중에 추가해도 됩니다.

  3. STEP 3
    뷰어에서 공부

    슬라이드와 설명을 나란히 보고, 궁금하면 그 자리에서 AI에게 질문합니다.

  4. STEP 4
    강의 후 보강

    녹음본·판서 사진을 추가해 강의자의 설명을 슬라이드에 덧붙입니다.

비용은 어떻게 되나요

LecAI 자체는 무료이며, AI 분석은 본인의 OpenAI API Key로 직접 결제됩니다. 기본 모델(GPT-5.6 Luna) 기준으로 슬라이드 60장짜리 강의 한 편 분석은 보통 수십 원, 1시간 녹음 음성 인식은 약 300원 수준입니다. 사용량과 비용은 대시보드와 설정에서 바로 확인할 수 있습니다.
